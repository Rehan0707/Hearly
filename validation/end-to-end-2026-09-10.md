## Blocked or unverified

1. **Virtual microphone route — BLOCKED.** `Hearly Microphone` is absent from `system_profiler SPAudioDataType`, and `/Library/Audio/Plug-Ins/HAL/HearlyAudio.driver` is not installed. Meet/Zoom/Teams device selection and end-to-end audio delivery were not testable without changing system audio state.
2. **Native voice processing — RISK/BLOCKER.** The native README and UI identify the current processor as an energy gate; the trained native ONNX adapter is not wired. The release preflight reports `HEARLY_NATIVE_MODEL` missing.
3. **Extension runtime loading — UNVERIFIED.** Isolated Chrome opened `chrome://extensions`, but the launch-time `--load-extension` flags did not expose a Hearly card. The manual `Load unpacked` picker opened and was canceled without submitting a path. Unit-level voice, VAD, crypto, streaming, and processor coverage remains green, but popup/content-script runtime behavior in Chrome needs a follow-up pass.
4. **Release packaging — BLOCKED.** Preflight reports no active full Xcode developer directory, no Developer ID Application identity, no `NOTARY_PROFILE`, and no `VITE_MACOS_DOWNLOAD_URL`.
